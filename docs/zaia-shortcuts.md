# ZAIA Shortcuts

Auf macOS verwendet ZAIA `Cmd`, auf Windows und Linux entsprechend `Ctrl`.
Die bekannten Zotero-Standardshortcuts fuer `Cmd/Ctrl+Shift+N/O/L/K/A/C/R`
werden nicht registriert oder ueberschrieben.

- `Cmd/Ctrl+Shift+I` - ZAIA oeffnen, fokussieren oder bei aktivem ZAIA-Fokus schliessen
- `Cmd/Ctrl+Shift+M` - Neuen ZAIA-Chat starten und Eingabefeld fokussieren
- `Cmd/Ctrl+Shift+P` - ZAIA-Popout oeffnen oder fokussieren
- `Cmd/Ctrl+Shift+F` - Aktuellen Chat favorisieren oder Favorit entfernen
- `Cmd/Ctrl+Shift+T` - Kontextfenster oeffnen
- `Cmd/Ctrl+Shift+D` - Modellauswahl aufklappen oder fokussieren
